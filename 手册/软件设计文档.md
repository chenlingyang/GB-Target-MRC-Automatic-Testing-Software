# 图像采集卡上位机软件设计文档

## 1. 项目概述

### 1.1 项目名称
图像采集卡上位机软件

### 1.2 项目目标
开发一个基于Windows平台的图像采集卡上位机软件，实现图像采集、显示、处理和存储功能。

### 1.3 开发环境
- **开发工具**: Visual Studio 2022
- **编程语言**: C++ / C#
- **操作系统**: Windows 10/11
- **图像处理库**: OpenCV / EmguCV (C#) 或 OpenCV (C++)

## 2. 功能需求

### 2.1 核心功能

#### 2.1.1 图像采集
- 连接并识别图像采集卡设备
- 实时采集图像数据
- 支持多种图像格式（RGB、YUV等）
- 可配置采集参数（分辨率、帧率等）

#### 2.1.2 图像显示
- 实时显示采集的图像
- 支持图像放大功能（缩放比例可调）
- 支持图像缩小功能（缩放比例可调）
- 支持鼠标滚轮缩放
- 支持图像平移（当图像放大超出显示区域时）

#### 2.1.3 图像处理
- 图像灰度化处理
- 实时预览处理效果
- 可切换原始图像和处理后图像显示

#### 2.1.4 图像存储
- 保存当前显示的图像
- 支持多种图像格式（BMP、JPEG、PNG等）
- 可选择保存路径和文件名
- 支持批量保存功能

### 2.2 辅助功能
- 图像信息显示（分辨率、位深、帧率等）
- 采集参数配置界面
- 图像处理参数调整
- 历史记录查看

## 3. 技术架构

### 3.1 架构设计

```

                    ↓

└─────────────────────────────────────────┘
                    ↓

```

### 3.2 技术选型

#### 方案一：C# + WPF + EmguCV
- **优点**: 开发效率高，界面美观，跨平台潜力
- **缺点**: 性能略低于C++
- **适用场景**: 快速开发，界面要求高

#### 方案二：C++ + Qt + OpenCV
- **优点**: 性能优秀，跨平台，界面美观
- **缺点**: 开发周期较长
- **适用场景**: 性能要求高，需要跨平台

#### 方案三：C++ + MFC + OpenCV
- **优点**: Windows原生，性能优秀
- **缺点**: 界面相对传统，仅限Windows
- **适用场景**: Windows专用，快速开发

**推荐方案**: C# + WPF + EmguCV（开发效率与性能平衡）

## 4. 模块设计

### 4.1 图像采集模块 (ImageCaptureModule)

#### 功能
- 初始化图像采集卡
- 启动/停止采集
- 获取图像数据
- 配置采集参数

#### 接口设计
```csharp
public class ImageCaptureModule
{
    // 初始化采集卡
    public bool Initialize(string deviceName);
    
    // 开始采集
    public bool StartCapture();
    
    // 停止采集
    public void StopCapture();
    
    // 获取当前帧
    public Mat GetCurrentFrame();
    
    // 设置采集参数
    public void SetResolution(int width, int height);
    public void SetFrameRate(int fps);
    
    // 事件：新帧到达
    public event EventHandler<Mat> FrameReceived;
}
```

### 4.2 图像处理模块 (ImageProcessingModule)

#### 功能
- 图像灰度化
- 图像缩放
- 图像平移
- 其他图像处理算法

#### 接口设计
```csharp
public class ImageProcessingModule
{
    // 灰度化处理
    public Mat ConvertToGrayscale(Mat source);
    
    // 图像缩放
    public Mat ResizeImage(Mat source, double scale);
    public Mat ResizeImage(Mat source, int width, int height);
    
    // 图像裁剪（用于平移显示）
    public Mat CropImage(Mat source, Rectangle region);
}
```

### 4.3 图像显示模块 (ImageDisplayModule)

#### 功能
- 图像渲染显示
- 缩放控制
- 平移控制
- 鼠标交互

#### 接口设计
```csharp
public class ImageDisplayControl : UserControl
{
    // 设置显示的图像
    public void SetImage(Mat image);
    
    // 设置缩放比例
    public void SetZoom(double scale);
    
    // 重置视图
    public void ResetView();
    
    // 属性
    public double ZoomScale { get; set; }
    public Point PanOffset { get; set; }
}
```

### 4.4 图像存储模块 (ImageStorageModule)

#### 功能
- 保存图像到文件
- 选择保存格式
- 批量保存
- 历史记录管理

#### 接口设计
```csharp
public class ImageStorageModule
{
    // 保存图像
    public bool SaveImage(Mat image, string filePath, ImageFormat format);
    
    // 保存图像（带对话框选择路径）
    public bool SaveImageWithDialog(Mat image);
    
    // 批量保存
    public bool SaveImages(List<Mat> images, string directory, ImageFormat format);
}
```

## 6. 数据流设计

### 6.1 图像采集流程
```
图像采集卡 → 驱动接口 → 原始图像数据 → 图像处理模块 → 显示模块
                                                      ↓
                                                存储模块（可选）
```

### 6.2 图像处理流程
```
原始图像 → 灰度化处理 → 处理后图像 → 显示更新
```

### 6.3 缩放显示流程
```
原始图像 → 缩放计算 → 缩放后图像 → 显示更新
```

## 7. 关键技术实现

### 7.1 图像采集卡接口
- 使用采集卡厂商提供的SDK
- 常见接口：DirectShow、V4L2（Linux）、厂商专用API
- 需要根据具体采集卡型号选择对应驱动

### 7.2 图像缩放实现
- 使用双线性插值或双三次插值算法
- OpenCV的resize函数
- 支持实时缩放预览

### 7.3 图像灰度化实现
- RGB转灰度公式：Gray = 0.299*R + 0.587*G + 0.114*B
- 使用OpenCV的cvtColor函数

### 7.4 图像存储实现
- 使用OpenCV的imwrite函数
- 支持多种格式：BMP、JPEG、PNG、TIFF等

## 10. 注意事项

### 10.1 性能考虑
- 图像处理操作应在后台线程执行，避免阻塞UI
- 使用异步操作处理图像采集
- 合理使用内存，及时释放图像资源

### 10.2 兼容性
- 需要确认图像采集卡的驱动和SDK兼容性
- 测试不同Windows版本的兼容性
- 考虑32位和64位系统支持

### 10.3 错误处理
- 采集卡连接失败处理
- 图像格式错误处理
- 文件保存失败处理
- 内存不足处理
