## 1. 引言

### 1.1 编写目的

本手册面向**终端操作人员**与**现场调试人员**，说明如何在 Windows 环境下安装依赖、配置采集与相机参数、完成实时预览、批量存图、以及运行 MRC（最小可分辨对比度相关）批处理与实时分析。

### 1.2 读者对象与前置知识

读者应能够：

- 使用 Windows 文件资源管理器与常见对话框（打开文件、选择文件夹）；
- 理解最基本的图像格式（PNG、JPG、TIF）与文件夹路径概念；
- 在必要时联系厂商工程师配合安装 **Teledyne DALSA SaperaLT** 驱动与 **.NET 组件**，并提供相机 **CCF** 配置文件。

### 1.3 术语与缩写

| 术语 | 含义 |
|------|------|
| 上位机 | 本 Windows 桌面应用程序 |
| SaperaLT | Teledyne DALSA 图像采集软件开发包/运行时 |
| CCF | 相机/采集配置文件（Sapera 常用文本配置） |
| MRC | 本系统中由 Python 脚本执行的靶标分析流程（输出标注图、Excel、曲线等） |
| EmguCV | OpenCV 的 .NET 封装，用于图像读写与部分处理 |

### 1.4 参考资料

- 仓库内：`TeledyneDALSA_对接说明.md`（DLL/CCF 排查补充）、`VS调试运行说明.md`（开发人员调试）
- Teledyne DALSA 官方 SaperaLT 文档与相机厂商说明

## 2. 产品概述

### 2.1 功能清单（与当前版本一致）

| 功能 | 说明 |
|------|------|
| 图像采集 | **固定使用 Teledyne DALSA（SaperaLT）** 采集链路；界面中采集源下拉框不可切换 |
| 实时预览 | 左侧「实时采集预览」区域显示当前帧；支持灰度化开关 |
| 缩放与平移 | 工具栏与菜单提供缩放/重置；**Ctrl + 鼠标滚轮**缩放；**Shift + 左键拖拽**或**中键拖拽**平移 |
| 单帧保存 | **Ctrl + S** 或「保存」按钮，格式由保存对话框选择 |
| 批量采集 | 指定张数、格式（PNG/JPG/TIF/RAW）、目录后批量抓取并保存（需先「开始采集」） |
| CCF 切换 | 选择 `.ccf` 并「应用 CCF」后重启采集链路 |
| MRC 实时 | 采集中开启「MRC处理」，按节流周期调用 Python 处理并在右侧显示结果 |
| MRC 批处理 | 选择含 bmp/jpg/png/tif 的文件夹，输出至 `mrc_result`，并生成 `mrc_summary.csv` |
| 结果查看 | 右侧「MRC 结果图」与「MRC 结果表」；点击表格行可加载对应标注图 |

### 2.2 设计限制（务必知晓）

1. **采集源不可选**：程序启动后将配置中的 `CaptureSource` 固定为 `TeledyneDalsaSaperaLt`，不再提供 DirectShow/USB 摄像头切换路径（源码中仍保留 `ImageCaptureModule` 类供开发扩展，但主界面逻辑不使用）。
2. **Sapera 帧率显示**：Sapera 模式下状态栏「帧率」可能显示为 **0**（当前实现未从驱动读取帧率）。
3. **MRC 实时性能**：实时 MRC 约 **每 1.2 秒**最多触发一次，以免阻塞界面。
4. **分辨率**：Sapera 模式下有效分辨率主要由 **缓冲/CCF/硬件** 决定；配置中的宽高可能被实际缓冲尺寸覆盖。

## 3. 运行环境与依赖

### 3.1 硬件与操作系统

- **操作系统**：Windows 10 / 11（64 位推荐）
- **采集硬件**：支持 SaperaLT 的 Teledyne DALSA 采集卡及相关相机链路
- **磁盘空间**：预留足够空间保存批量图像与 MRC 输出（Excel、PNG 等）

### 3.2 必备软件依赖

| 依赖 | 用途 |
|------|------|
| **Teledyne DALSA SaperaLT**（含驱动） | 采集卡与 Sapera API |
| **DALSA.SaperaLT.SapClassBasic.dll** | .NET 绑定（程序通过反射加载；可在配置中指定路径） |
| **相机 CCF 文件** | 初始化采集资源（界面可选路径或放置于约定搜索路径） |
| **Python 3**（已加入 PATH，或安装在常见本地路径） | 执行 `Python/MRC_final.py` |
| **MRC 资源文件** | 与程序一同发布的 `Python/MRC_final.py`、`Python/MappingTable.xlsx`（生成输出时会复制到输出目录附近） |

### 3.3 开发与编译环境（仅开发人员）

- Visual Studio 2022，**.NET 8.0** 桌面开发工作负载
- NuGet：`Emgu.CV`、`Emgu.CV.runtime.windows`（版本以 `ImageCaptureApp.csproj` 为准）

## 4. 安装与首次启动

### 4.1 部署程序文件

将发布目录（含 `ImageCaptureApp.exe`）解压或复制到目标机固定路径，确保同级存在：

- `Config/CaptureDeviceConfig.json`（首次运行若缺失会尝试生成默认配置）
- `Python/MRC_final.py`、`Python/MappingTable.xlsx`（来自项目生成输出）

### 4.2 配置 Sapera .NET DLL

若程序提示未找到 `DALSA.SaperaLT.SapClassBasic.dll`：

1. 在本机 Sapera 安装目录查找（常见：`...\Teledyne DALSA\Sapera\Components\NET\Bin\`）。
2. 将完整路径写入配置文件项 `DeviceSettings.SaperaDotNetDllPath`（见第 7 节）。
3. 或将 DLL 部署到程序搜索路径之一（程序会在 exe 目录、`Program Files` 等常见路径自动探测）。

### 4.3 配置 CCF

CCF 为 **必填**。任选其一：

- 在配置文件设置 `DeviceSettings.SaperaCcfPath`；
- 或将 `mycamera.ccf` 放在 exe 目录或项目约定的上级目录（程序内置若干候选路径）；
- 或在界面「CCF切换」区域选择文件并点击「应用 CCF」。

### 4.4 启动程序

双击 `ImageCaptureApp.exe`。若初始化失败，界面状态栏与弹窗会给出 **LastError** 摘要（如：找不到 DLL、找不到 CCF、无可用采集服务器等）。

## 5. 用户界面说明

主窗口自上而下依次为：

1. **菜单栏**：文件（保存、退出）、视图（缩放）、处理（灰度化）、帮助（关于）。
2. **工具栏**：采集源显示（禁用，固定 SaperaLT）、开始/停止采集、保存、灰度化、缩放按钮、**MRC处理**（实时开关）。
3. **参数区（边框卡片）**  
   - **批量采集**：张数、格式、保存路径、进度。  
   - **MRC处理**：待处理图像文件夹、批处理进度。  
   - **CCF切换**：当前 CCF 路径、选择与应用。
4. **双栏图像区**  
   - 左：**实时采集预览**  
   - 右：**MRC 结果图**（脚本输出的标注图等）、下方 **MRC 结果表**（最小分辨组、C 值、状态等）。
5. **状态栏**：分辨率、帧率、缩放百分比、文字状态。

## 6. 操作指南（按任务）

### 6.1 启动采集并预览

1. 确认 Sapera 服务正常、线缆连接可靠。
2. 确认 CCF 与 DLL 路径有效。
3. 点击 **「开始采集」**。成功后左侧预览应连续刷新。
4. 点击 **「停止采集」** 结束数据流。

若启动失败：根据弹窗提示检查 DLL、CCF、采集卡是否被其它程序占用。

### 6.2 调整显示（缩放 / 平移 / 灰度）

- **放大/缩小**：工具栏按钮，或 **Ctrl + “+” / “-”**。
- **重置视图**：工具栏「重置」或 **Ctrl + 0**。
- **滚轮缩放**：**Ctrl + 鼠标滚轮**。
- **平移**：**Shift + 左键拖拽**，或 **鼠标中键拖拽**。
- **灰度化**：切换彩色/灰度显示（仅影响显示与后续保存的当前帧内容是否经灰度处理）。

### 6.3 保存单帧图像

1. 确保当前已有图像（正在采集或暂停前有最后一帧）。
2. 按 **Ctrl + S** 或点「保存」。
3. 在对话框中选择路径与扩展名；格式由扩展名和过滤器共同决定。

### 6.4 批量采集

1. 点击 **「开始采集」**。
2. 在「批量采集」区域设置 **张数**、**格式**（PNG / JPG / TIF / RAW）。
3. 点击 **「浏览…」** 选择保存目录（需有写权限）。
4. 点击 **「批量采集」**，等待进度显示完成。

命名规则示例：`capture_yyyyMMdd_HHmmss_0001.png`（序号递增）。若成功数量少于设定张数，可能与丢帧、磁盘写入失败或采集中断有关。

### 6.5 切换 CCF（更换相机配置）

1. 点击 **「选择CCF…」** 选取目标 `.ccf`。
2. 点击 **「应用 CCF」**。程序会停止采集、重新初始化采集模块、写入配置；若之前在采集，会尝试自动恢复采集。
3. 若提示初始化失败，检查 CCF 与当前硬件是否匹配。

### 6.6 MRC 实时处理

1. 先 **开始采集**。
2. 点击 **「MRC处理」** 开启实时模式（按钮变为「停止MRC实时」）。
3. 程序按节流周期将当前帧送入 Python 流水线，**右侧结果图**与**结果表**会更新；输出目录默认取「批量采集」中的保存路径，若无效则回退到用户「图片」目录下的 `Captures`。
4. 再次点击停止实时 MRC。

**依赖检查**：若提示找不到脚本或映射表，确认 `Python` 目录随程序发布；若提示 Python 错误码 **9009**，请安装 Python 并配置 `python` 或 `py -3`。

### 6.7 MRC 文件夹批处理

1. 在「MRC处理」区域点击 **「浏览…」** 选择仅含图像文件的文件夹（支持 `.bmp` `.jpg` `.jpeg` `.png` `.tif` `.tiff`，不递归子文件夹）。
2. 点击 **「处理文件夹」**。
3. 处理完成后：  
   - 每张图在 `所选文件夹/mrc_result/<图像名>/` 下生成输出；  
   - 汇总表路径：`所选文件夹/mrc_result/mrc_summary.csv`。  
4. 弹窗会报告成功/失败数量；第一张成功的标注图会自动尝试显示在右侧。

### 6.8 在结果表中回看

在「MRC 结果表」中单击一行，若该行记录了有效的 `LabeledImagePath` 且文件仍存在，右侧会加载对应标注图。

## 7. 配置文件说明

### 7.1 路径优先级

程序优先读取 **可执行文件目录** 下的：

`Config/CaptureDeviceConfig.json`

若调试阶段运行目录无该文件，可能回退复制源码树中的配置（详见 `CaptureDeviceConfig.Load()` 实现）。

### 7.2 主要字段（节选）

```json
{
  "DeviceSettings": {
    "CaptureSource": "TeledyneDalsaSaperaLt",
    "DeviceIndex": 0,
    "DeviceName": "Xtium-CL MX4",
    "API": "SaperaLT",
    "SaperaDotNetDllPath": "",
    "SaperaCcfPath": "",
    "Resolution": { "Width": 1280, "Height": 720 },
    "FrameRate": 30,
    "AutoStart": false
  },
  "DisplaySettings": {
    "DefaultZoom": 1.0,
    "MinZoom": 0.1,
    "MaxZoom": 10.0
  },
  "StorageSettings": {
    "DefaultFormat": "PNG",
    "DefaultSavePath": "",
    "AutoSave": false
  }
}
```

| 字段 | 说明 |
|------|------|
| `CaptureSource` | 运行时由程序强制为 `TeledyneDalsaSaperaLt`，不必手动切换 |
| `SaperaDotNetDllPath` | `DALSA.SaperaLT.SapClassBasic.dll` 完整路径；空则自动探测 |
| `SaperaCcfPath` | CCF 完整路径；也可通过界面应用 |
| `Resolution` / `FrameRate` | 期望配置；Sapera 实际值以缓冲与硬件为准 |
| `AutoStart` | `true` 时初始化成功后自动开始采集 |
| `StorageSettings.DefaultFormat` | 与界面「批量采集」格式联动（PNG/JPG/TIF/RAW） |

## 8. MRC 输出物说明

对单次处理（实时或批处理），脚本成功后常见输出包括（文件名随输入 stem 变化）：

| 文件 | 说明 |
|------|------|
| `*_labels.png` | 标注结果图（程序以此判定成功） |
| `*_ov.png` | 概览图（若脚本生成） |
| `*_res.xlsx` | Excel 结果 |
| `*_curve.png` | 曲线图（若脚本生成） |
| `*_summary.json` | 摘要 JSON；程序读取最小分辨组与 C 均值填入表格 |

若脚本退出码非 0 或未生成 `*_labels.png`，界面会给出失败原因摘要（含 Python 输出截取）。

## 9. 故障排除

| 现象 | 可能原因 | 建议措施 |
|------|----------|----------|
| 初始化失败：未找到 DLL | Sapera .NET 组件未安装或路径错误 | 指定 `SaperaDotNetDllPath` 或安装 SaperaLT |
| 初始化失败：未找到 CCF | 路径为空且默认搜索失败 | 界面选择 CCF 或放置 `mycamera.ccf` |
| 未找到可用 Sapera 服务器 | 驱动未装、卡未上电、服务异常 | 检查设备管理器与 Sapera 配置工具 |
| Python 9009 | 未安装或未配置 PATH | 安装 Python 3，确保命令行可运行 `python` 或 `py -3` |
| MRC 提示缺少 MappingTable | xlsx 未随程序发布 | 恢复 `Python/MappingTable.xlsx` |
| 批量采集成功张数偏少 | 采集未持续、磁盘权限、帧抓取失败 | 保持采集运行，检查路径权限与杀毒拦截 |
| 帧率始终为 0 | Sapera 模块未实现 FPS 查询 | 可忽略或用外部工具评估 |

## 10. 安全与维护

- 定期备份 `Config/CaptureDeviceConfig.json` 与常用 CCF。
- 批量与 MRC 输出目录应位于专用数据盘，避免系统盘写满。
- 升级程序时同步替换 `Python` 目录，避免脚本与上位机版本不匹配。

## 11. 附录 A — 启动与数据流（简图）

```
程序启动
  → 读取 CaptureDeviceConfig.json
  → 构造 TeledyneDalsaSaperaLtCaptureModule

     用户保存 / 批量采集 / MRC（调用 Python）
```
