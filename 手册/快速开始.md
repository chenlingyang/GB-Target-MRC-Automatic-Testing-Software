# 快速开始指南

## 环境准备

1. **安装 Visual Studio 2022**
   - 下载地址：https://visualstudio.microsoft.com/
   - 安装时选择 ".NET 桌面开发" 工作负载

2. **安装 .NET 6.0 SDK**（如果 Visual Studio 未包含）
   - 下载地址：https://dotnet.microsoft.com/download

## 打开项目

1. 双击 `ImageCaptureApp.sln` 文件，在 Visual Studio 中打开项目

2. 等待 NuGet 包自动还原（首次打开可能需要几分钟）

## 编译项目

1. 按 `F6` 或选择菜单：**生成** → **生成解决方案**

2. 如果编译成功，会在 `ImageCaptureApp\bin\Debug\net6.0-windows\` 目录下生成可执行文件

## 运行项目

1. 按 `F5` 或点击工具栏的"启动"按钮

2. 确保已连接图像采集设备（USB摄像头或图像采集卡）

3. 点击"开始采集"按钮开始采集图像

## 功能使用

### 图像采集
- **开始采集**：点击工具栏"开始采集"按钮
- **停止采集**：点击工具栏"停止采集"按钮

### 图像缩放
- **放大**：点击"放大"按钮，或按 `Ctrl + +`
- **缩小**：点击"缩小"按钮，或按 `Ctrl + -`
- **鼠标滚轮缩放**：按住 `Ctrl` 键，滚动鼠标滚轮
- **重置视图**：点击"重置"按钮，或按 `Ctrl + 0`

### 图像平移
- **平移**：按住 `Shift` 键 + 左键拖拽，或中键拖拽

### 图像处理
- **灰度化**：点击"灰度化"按钮，再次点击恢复彩色

### 图像保存
- **保存**：点击"保存"按钮，或按 `Ctrl + S`
- 支持格式：PNG、JPEG、BMP、TIFF

## 常见问题

### Q: 提示"未检测到采集卡设备"
**解决方案：**
1. 检查设备是否已正确连接
2. 检查设备驱动是否已安装
3. 在 Windows 设备管理器中确认设备显示正常
4. 尝试更换 USB 端口（如果是 USB 设备）

### Q: NuGet 包还原失败
**解决方案：**
1. 检查网络连接
2. 在 Visual Studio 中：**工具** → **NuGet 包管理器** → **程序包管理器控制台**
3. 运行命令：`Update-Package -reinstall`

### Q: 编译错误：找不到 EmguCV
**解决方案：**
1. 右键点击项目 → **管理 NuGet 程序包**
2. 搜索 "Emgu.CV" 并安装
3. 搜索 "Emgu.CV.runtime.windows" 并安装

### Q: 运行时错误：找不到 DLL
**解决方案：**
1. 确保安装了 `Emgu.CV.runtime.windows` 包
2. 检查 `bin\Debug\net6.0-windows\` 目录下是否有 OpenCV 相关的 DLL 文件
3. 如果没有，重新生成项目

### Q: 图像显示卡顿
**解决方案：**
1. 降低采集分辨率（在代码中修改 `ImageCaptureModule.cs` 的 `Initialize` 方法）
2. 关闭其他占用资源的程序
3. 检查计算机性能是否足够
