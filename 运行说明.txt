========================================
图像采集卡上位机软件 - 运行说明
========================================

【快速运行方法】

方法1：使用 Visual Studio（推荐）
1. 双击 ImageCaptureApp.sln 文件
2. 等待 Visual Studio 打开并还原 NuGet 包
3. 按 F5 运行项目

方法2：使用批处理文件
1. 双击 "运行项目.bat" 文件
2. 等待自动编译和运行

方法3：使用命令行
打开 PowerShell，运行：
  cd ImageCaptureApp
  dotnet restore
  dotnet build
  dotnet run

【系统要求】
- Windows 10/11
- .NET 6.0 SDK 或更高版本
- Visual Studio 2022（可选，用于开发）

【首次运行】
1. 确保已连接图像采集设备（USB摄像头或采集卡）
2. 点击"开始采集"按钮
3. 如果提示"未检测到采集卡设备"，请检查设备连接和驱动

【功能说明】
- 开始采集：开始从采集卡获取图像
- 停止采集：停止图像采集
- 保存：保存当前显示的图像
- 灰度化：切换彩色/灰度模式
- 放大/缩小：缩放图像显示
- 重置：重置视图到原始大小

【快捷键】
- Ctrl + S：保存图像
- Ctrl + +：放大
- Ctrl + -：缩小
- Ctrl + 0：重置视图
- Ctrl + 滚轮：缩放图像
- Shift + 左键拖拽：平移图像

【常见问题】
1. 如果项目无法加载，删除 bin 和 obj 文件夹后重新打开
2. 如果 NuGet 包还原失败，检查网络连接
3. 如果运行时出错，确保已安装 .NET 6.0 SDK
