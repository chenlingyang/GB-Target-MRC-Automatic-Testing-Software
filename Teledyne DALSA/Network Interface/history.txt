    Added

		BGRa 8-bit
		Green Only 8-Bit
		BiColorRGBG8
		BiColorRGBG12
		BiColorRGBG12Packed
		RGB12V1Packed
		RGB8

    Fixes
	- Fixed potential memory leaks when using TurboDrive. 
	- Improved the installation package to insure the GigE Generic driver integrity, while updating the Genie Framework on Sapera 8.00 and higher versions.

5.00.00.0703
May 12th, 2017

    Added
	- Teledyne DALSA Sapera GigE Vision Filter Driver was completely redesigned based on Microsoft Network Driver Interface
	  Specification (NDIS) 6.20 to improve performance and reliability for 32-bit & 64-bit systems  running versions of
	  Microsoft Windows 7 and later.
	- The previous architecture based on NDIS 5.1 is kept with previous version of Microsoft Windows (Windows XP & Vista).

5.10.00.0771
November 14th, 2017

    Added
	- Support for Turbo Drive Version 1 with metadata.
	- Support for Turbo Drive Version 2. (mono 8-bit and Bayer only, when metadata is disabled).
	- Support for Sapera function CorManGetServerByDeviceUserId.
	- Changed Kernel drivers signing to comply with Windows 10 and Secure Boot requirements – this was preventing installation
	  of the software.
	- Necessary DLL to the Network Imaging Package to allow the use of Genie Mono, Genie Color and Genie HM with Teledyne
	  DALSA interface (as opposed to GigE Vision interface). This is supported on all supported OS, including WoW64.

    Fixes
	- BSOD that could occur while logging messages.
	- Possible BSOD with “next empty” cycling mode.
	- Reduced default interface memory size from 32MB to 16MB in 32-bits system to avoid kernel memory allocation problems.
	- Fixed the possibility that the DHCP server could be disabled on a NIC at Windows startup (for Windows Vista and up only). 

5.11.00.0772
